# BAOCAOSISO - Ban don dep cho GitHub

Giai nen ca hai tep ZIP vao cung mot thu muc. Upload **noi dung** thu muc BAOCAOSISO-main len repository, khong upload ZIP.

Khong xoa source, SQL, config, public assets, service worker, lockfile.

Lenh kiem tra tai may co Node 20+: npm ci && npm run lint && npm run build
Chua chay build hay kiem thu Supabase trong moi truong nay.
